# 用户使用指南

---

## 界面总览

应用主界面分为以下几个模块：

| 区域 | 说明 |
|------|------|
| 顶部导航栏 | 在各功能页面间切换，显示应用状态 |
| 监控页面 | 配置并启动微信直播监控 |
| 录制页面 | 查看当前录制状态，手动控制录制 |
| 分析页面 | 对录制内容进行 AI 分析 |
| 报告页面 | 查看提取的问答对与知识摘要 |
| 设置页面 | 配置 API 密钥、录制参数等 |

---

## 账号与 API 配置

1. 打开**设置**页面
2. 在「AI 配置」下选择 LLM 提供商：
   - **通义千问**：填入 `DASHSCOPE_API_KEY`
   - **OpenAI GPT**：填入 `OPENAI_API_KEY`
   - **Anthropic Claude**：填入 `ANTHROPIC_API_KEY`
3. 在「语音转录」下填入 Whisper API Key
4. 选择模型与温度参数（建议保持默认）
5. 点击**保存**，系统自动验证连接

---

## 监控配置

### 添加监控目标

1. 进入**监控**页面
2. 点击「添加监控」
3. 填写以下信息：
   - **直播名称**：便于识别的标签
   - **检测关键词**：微信窗口标题中的关键字
   - **检测间隔**：建议 30 秒
4. 勾选「自动开始录制」（可选）
5. 点击**保存**

### 启动监控

点击**开始监控**，系统进入循环检测模式：
- 🟡 检测中 — 正在扫描微信窗口
- 🟢 直播进行中 — 检测到目标直播
- 🔴 录制中 — 正在录制音视频

---

## 手动录制控制

如需手动控制，进入**录制**页面：

1. **选择屏幕区域**：点击「选择区域」框选录制范围
2. **选择音频设备**：从下拉框选择麦克风或系统音频
3. **点击开始录制**：录制状态变为 🔴
4. **点击停止录制**：文件自动保存到 `backend/storage/recordings/`

---

## 运行分析

1. 进入**分析**页面
2. 从列表中选择要分析的录制文件
3. 配置分析选项：
   - ✅ 语音转录（Whisper）
   - ✅ OCR 文字识别
   - ✅ AI 内容分析
   - ✅ 问答对提取
4. 点击**开始分析**
5. 进度条显示各阶段状态，分析约需 2-10 分钟

---

## 查看问答对与转录

分析完成后：

- **转录文本**标签页：完整时间轴字幕
- **问答对**标签页：AI 提取的知识点问答
- **摘要**标签页：课程核心内容摘要

支持关键词搜索与按主题筛选。

---

## 导出报告

1. 在**报告**页面点击**导出**
2. 选择格式：
   - **Markdown**：`.md` 文件，适合笔记软件（如 Obsidian、Notion）
   - **Excel**：`.xlsx` 表格，便于整理归档
3. 选择保存路径
4. 点击**确认导出**

---

## 使用技巧

- 📡 **网络稳定性**：Whisper 转录需要稳定网络，建议使用有线网络
- 🔊 **音频质量**：系统音量建议保持在 60%+ 以提升转录准确率
- 💡 **直播画面**：保持直播窗口可见（不要最小化），OCR 效果更佳
- 🗂️ **定期清理**：录制文件较大，分析完成后可归档原始视频
- ⏰ **分段录制**：超过 2 小时的直播建议开启自动分段功能（设置中配置）
