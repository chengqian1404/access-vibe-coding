# 用户指南

## 快速入门

### 第一步：配置 LLM

1. 打开 Access Vibe Coding
2. 点击左侧 **设置**
3. 选择 LLM 提供商（推荐：通义千问或 DeepSeek）
4. 填入 API Key
5. 点击 **测试连接**，确认 ✓ 连接成功
6. 点击 **保存配置**

### 第二步：打开 Microsoft Access

在执行操作前，请先在电脑上打开 Microsoft Access 并打开你的数据库文件。

> **注意：** Access 自动化功能仅在 Windows 系统上有效。

### 第三步：输入指令

在主页的输入框中用中文描述你的需求：

```
创建一个"员工信息"表，包含员工ID、姓名、部门、工资字段
```

点击 **执行指令** 或按 **Ctrl+Enter** 开始执行。

## 界面功能说明

### 主页

- **指令输入区**：输入自然语言指令
- **执行状态面板**：显示当前执行进度和状态
- **执行日志**：详细的操作日志，可导出
- **截图预览**：Access 当前界面截图

### 指令模板页

预设常用操作模板，点击 **使用** 快速填入指令。

### 历史记录页

查看所有历史执行记录，支持：
- 点击 ▶ 按钮重新执行
- 点击 🗑 删除记录
- 清空所有历史

### 设置页

- 配置 LLM 提供商和 API Key
- 设置默认提供商

---

## 注意事项

1. **Windows 专用**：Access 自动化功能仅在 Windows 上工作
2. **保持 Access 前台**：执行期间不要最小化 Access 窗口
3. **先备份数据**：对重要数据库操作前请先备份
4. **指令要清晰**：越详细的指令，执行越准确
5. **API 密钥安全**：密钥加密存储在本地，不会上传到任何服务器（除对应 LLM 提供商）
