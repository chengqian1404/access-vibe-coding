# Access Agent 架构文档

## 概述

Access Agent 是一个 AI 驱动的 Microsoft Access 自动化代理，通过自然语言指令操作 Access 数据库。

## 系统架构

```
┌──────────────────────────────────────────────┐
│                  用户界面层                    │
│         （命令行 / GUI / Web API）              │
└─────────────────┬────────────────────────────┘
                  │ 自然语言指令
┌─────────────────▼────────────────────────────┐
│                  LLM 处理层                    │
│   OpenAI / 通义千问 / Claude / DeepSeek        │
│        （指令理解 + 意图识别）                  │
└─────────────────┬────────────────────────────┘
                  │ 结构化操作指令
┌─────────────────▼────────────────────────────┐
│                  Agent 核心层                  │
│         （任务规划 + 动作执行）                  │
└─────────────────┬────────────────────────────┘
                  │ 数据库操作
┌─────────────────▼────────────────────────────┐
│               Access 适配器层                  │
│     （pyodbc / win32com / mdb-reader）          │
└─────────────────┬────────────────────────────┘
                  │
┌─────────────────▼────────────────────────────┐
│            Microsoft Access 数据库             │
└──────────────────────────────────────────────┘
```

## 核心模块

### 1. 自然语言处理模块（`agent/nlp/`）
- 接收用户的自然语言指令
- 调用 LLM API 解析意图
- 生成结构化的操作计划

### 2. Agent 核心模块（`agent/core/`）
- 任务规划与调度
- 多步骤操作编排
- 错误恢复与重试

### 3. Access 适配器模块（`agent/adapters/access/`）
- 连接 Access 数据库
- 执行 SQL 查询
- 表格/记录的增删改查
- 支持 `.mdb` 和 `.accdb` 格式

### 4. LLM 提供商模块（`agent/llm/`）
- 统一的 LLM 接口抽象
- 支持多个提供商（OpenAI、通义千问、Claude、DeepSeek）
- 自动故障转移和重试

### 5. 配置模块（`agent/config/`）
- 环境变量管理
- LLM API 密钥配置
- 数据库连接配置

## 数据流

```
用户输入 → NLP 解析 → 意图识别 → 动作规划 → Access 操作 → 结果返回
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| LLM 框架 | LangChain / 直接 API |
| 数据库连接 | pyodbc / win32com |
| 配置管理 | pydantic-settings |
| 日志 | structlog |
| 测试 | pytest |
