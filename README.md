# Access Agent - 自然语言 Access 自动化工具

这是一个 AI 驱动的 Microsoft Access 自动化代理，可以通过自然语言指令自动操作 Access 数据库。

## 功能特性
- 自然语言指令转换为 Access 操作
- 支持多个 LLM 提供商（OpenAI、通义千问、Claude、DeepSeek）
- 跨平台支持（Windows、macOS、Linux）
- 完整的错误处理和日志记录
